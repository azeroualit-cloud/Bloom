# Bloom UI Rhythm Implementation Plan

> Execute natively in this session, task by task. The user explicitly authorized implementing the complete review; no design approval pause is needed.

**Goal:** Correct the reported spacing defects and complete the agreed Library, Map, editor and app-icon redesign.
**Architecture:** Preserve SwiftUI navigation, UIKit text editing, native MapKit clustering and existing storage. Centralize the 4/8/12/16/24 pt rhythm and 44 pt targets. Make categories destinations, map markers points, and editing controls direct actions.

**Spec:** User screenshots and the immediately preceding UI/UX review in this session.

## Global constraints
- Preserve note content, attachments, tags, exact coordinates, Dropbox saves, conflicts, recovery and offline operation.
- Uniform map-header columns; keyboard actions at least 44 pt and evenly distributed at 320 pt width.
- Library cards compact, distinct category symbols, no ambiguous stack/trash badge; all/unfiled destinations side by side.
- Visible name Appunti; unfiled label Da organizzare. Internal persistence identifiers stay compatible.
- Map counts mean grouped places. Note counts and thumbnails belong in the selected-place panel.
- Flower icon uses a continuous blue/lavender/berry gradient across the full silhouette; opaque RGB, 1024 square, matching appearance variants.

## Review focus
- Long titles and larger fonts must retain usable actions and scrolling.
- Keyboard must not cover controls or draw document text underneath a descriptive banner.
- Dense map points must zoom, remain tappable, preserve coordinates and open real notes.
- Menu-based selection must retain bulk archive, undo and tag editing.
- Tab labels must remain visually separate from scrolling content.
